# Proteasome Technical-Replicate QC

Upload two Excel workbooks produced by the Proteasome ProSight analysis app. The app compares all detected masses using an adjustable Da tolerance and appends only two QC sheets to a copy of technical replicate 1:

- `Recurring candidates`
- `Non-recurring candidates`

Manual QC and reviewer notes can be entered directly in the Streamlit tables before download. Original replicate-1 analysis sheets are preserved.
